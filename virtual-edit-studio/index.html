05 / QUESTIONS

Before you log in.

Can an editor really start in 30 minutes?+

That is our target for activating an editor in an already prepared, validated bay when the required media and licenses are ready. Initial workstation setup, source ingest and advanced customizations take longer. We will define a realistic onboarding window in your pilot scope.

Do I have to use PostOpz project structure?+

No. The PostOpz Framework is the default. Select custom configuration and we can scope your team's naming, folder structure, templates, permissions and handoff conventions.

Are Adobe, Avid and DaVinci Resolve all included?+

The first pilot is designed around a validated Premiere Pro workflow. Adobe and other NLE software licenses are the customer's responsibility unless expressly agreed. Avid and Resolve environments require a separate compatibility and licensing assessment.

What happens when I use all my GPU hours?+

Your selected plan has a monthly computing allowance, not unlimited 24/7 use. Overages, additional shifts and heavy workloads will be agreed in advance so cloud compute costs stay predictable.

Is storage backup or archive included?+

Shared active media capacity is included as specified. Backup, archive, retention, restores and bulk transfers require a separately documented policy and may incur additional fees. Cloud access is not a backup strategy.

Can an existing PostOpz managed-infrastructure customer add bays?+

Yes, this is a planned add-on path. A custom team quote can credit existing shared media management and support arrangements so your production does not pay twice for the same services.
