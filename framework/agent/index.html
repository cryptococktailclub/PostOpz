Why this exists

Software knowledge is not production knowledge.

An AI system can know Media Composer terminology and still fail at the operating logic of a real long-form project. Framework Agent Edition is designed to supply that missing workflow layer.

Project architecture

Teach agents how professional projects, bins, naming conventions, and media structures should be organized.

Editorial preparation

Ground recommendations around sync maps, grouping, ScriptSync, stringouts, review exports, and handoffs.

Operational reasoning

Help agents understand downstream consequences so they can recommend workflows that survive turnovers, revisions, and archive.

Integration model

License the knowledge layer. Keep the source protected.

The production API sits behind authenticated retrieval endpoints. Agents receive task-specific structured guidance, not the underlying Framework source files.

1. Authenticate

Developer or studio receives licensed credentials tied to an account and usage policy.

2. Query

The agent requests a specific professional workflow answer, diagnostic, checklist, or next action.

3. Retrieve

PostOpz returns scoped, structured guidance grounded in the canonical Framework knowledge base.
