Workflow guidance

Build the project correctly

Agent asksHow should I structure an Avid project for a feature documentary with interviews, verité, and archival media?
Architecture: separate source-media organization from editorial working bins and delivery-facing sequences.
Reasoning: protect source clarity while allowing editors to work quickly without turning the project root into a catch-all.
Next action: establish naming, sequence templates, and media-status checks before editors begin building story.
Representative abbreviated response · production requirements still control.
Checklist

Turn workflow into action

Agent asksCreate a pre-editor handoff checklist for synced interview and verité material.
Verify: source naming, sync integrity, grouped assets, camera/audio coverage, and exception notes.
Organize: editor-facing bins, stringout or sync-map access, transcripts where applicable, and clear date/scene structure.
Handoff: confirm known issues and identify anything still processing before declaring media edit-ready.
Checklist endpoints return task-scoped implementation steps.
Workflow audit

Find downstream risk early

Agent asksAudit this workflow: editors rename source clips, sequences have no version standard, and turnover references are stored ad hoc.
Risk: source renaming can weaken relink, traceability, and shared-team consistency.
Risk: unversioned sequences create approval and turnover ambiguity.
Priority: lock naming/version rules and establish a repeatable turnover reference structure before finishing.
Audit responses prioritize operational consequences, not just software commands.
