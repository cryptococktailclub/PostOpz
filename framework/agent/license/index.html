Autonomous x402 Access · pay per call

Task-scoped machine retrieval
  • A successful x402 payment authorizes one task-scoped retrieval response from the specific paid endpoint.
  • Current unit pricing is $0.50 for workflow guidance, $0.35 for a checklist, and $0.75 for a workflow audit; the machine-readable payment requirement returned at request time controls the exact transaction.

What standard access does not grant

Model training

No training, fine-tuning, distillation, synthetic-data generation, or benchmark-dataset creation using the Framework corpus or systematic API extraction.

Corpus ingestion

No bulk embedding, indexing, mirroring, caching, or reconstruction intended to reproduce a substitute knowledge base.

Redistribution

No resale, sublicensing, public republication, dataset distribution, or transfer of the underlying Framework knowledge corpus.

OEM / white-label

No incorporation of the Framework corpus as a persistent knowledge layer inside a third-party commercial product without a separate written license.

Enterprise / Model License

A separate written enterprise agreement is required for model training, fine-tuning, distillation, corpus ingestion, OEM embedding, redistribution, high-volume commercial deployment outside the published access scopes, or other uses outside Developer, Studio, and bounded x402 retrieval.
