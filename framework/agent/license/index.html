Commercial license scope.

PostOpz Framework Agent Edition separates ordinary retrieval rights from model-training, corpus-ingestion, redistribution, and OEM rights. This page summarizes the intended commercial scope so developers, studios, and procurement teams can evaluate the product before purchase.

Business terms summary: this page is designed to make the product boundary clear and is not a substitute for legal advice. Checkout terms and any separately executed written agreement control where they differ.

Developer Agent License · $799/year

One internal agent or application
  • Authenticated access to the PostOpz Framework Agent API.
  • Up to 500 included retrieval queries per month.
  • Internal development, testing, and commercial prototyping for one agent or application.
  • Task-scoped answers, diagnostics, checklists, and workflow guidance may be shown to authorized users of that application.

Studio Agent License · $3,500/year

Internal post-team deployment
  • Authenticated access to the PostOpz Framework Agent API.
  • Up to 5,000 included retrieval queries per month.

  • Internal operational use across editorial preparation, workflow diagnostics, checklists, and project-standardization tasks.

What the standard licenses do not grant

Model training

No training, fine-tuning, distillation, synthetic-data generation, or benchmark-dataset creation using the Framework corpus or systematic API extraction.

Corpus ingestion

No bulk embedding, indexing, mirroring, caching, or reconstruction intended to reproduce a substitute knowledge base.

Redistribution

No resale, sublicensing, public republication, dataset distribution, or transfer of the underlying Framework knowledge corpus.

OEM / white-label

No incorporation of the Framework corpus as a persistent knowledge layer inside a third-party commercial product without a separate written license.

Enterprise / Model License

A separate written enterprise agreement is required for model training, fine-tuning, distillation, corpus ingestion, OEM embedding, redistribution, high-volume commercial deployment, or other uses outside the Developer or Studio scope. Contact hello@postopz.com.

Operational safeguards

  • API credentials should not be shared outside the licensed organization or application scope.
  • Automated scraping or query patterns intended to reconstruct the Framework are outside the license.
  • Do not submit source media or confidential production information unless you have authority to process it through the service.
  • Usage limits and access controls may be enforced to protect the licensed corpus and service availability.
  • Editorial guidance remains subject to project-specific requirements, network/vendor specifications, and professional judgment.
