Developer Quickstart

Connect an agent to professional Avid workflow knowledge.

The Agent API returns task-scoped professional workflow guidance rather than exposing the underlying Framework corpus. Public discovery endpoints require no key; retrieval endpoints require an active Developer, Studio, or Enterprise license.

1. Discover the product

Public API discovery

GET https://postopz-agent-api.onrender.com/v1/discover

Machine-readable manifest

/.well-known/postopz-agent.json

curl https://postopz-agent-api.onrender.com/v1/discover

2. Obtain licensed credentials

Choose a Developer or Studio license on the Agent Edition page. The production service is designed to provision an API key to the checkout email after a mapped successful purchase. Store the key like any other production secret.

Developer $799/year · 500 queries/month   Studio $3,500/year · 5,000 queries/month

3. Query workflow guidance

curl -X POST https://postopz-agent-api.onrender.com/v1/workflow/query \
  -H "Authorization: Bearer $POSTOPZ_AGENT_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "edition": "avid-vol1",
    "task": "Design a professional bin and sequence structure for a feature documentary with interviews, verite and archival media.",
    "desired_output": "structured_steps",
    "context": {
      "nle": "Avid Media Composer",
      "production_type": "feature documentary"
    }
  }'

4. Use the specialized routes

Workflow query

POST /v1/workflow/query
Professional guidance, diagnostics, structured steps, and next actions.

Checklist

POST /v1/workflow/checklist
Task-specific implementation and QC checklists.

Audit

POST /v1/workflow/audit
Evaluate structured project/workflow metadata against PostOpz standards.

License status

GET /v1/license
Inspect the active plan and usage associated with the supplied API key.

Expected HTTP behavior

  • 200 — successful licensed retrieval.
  • 401 — invalid, expired, or inactive credential.
  • 402 — active entitlement/payment required; the response can expose purchase options for an agent or developer.
  • 429 — monthly allowance or burst-rate limit reached.
  • 503 — retrieval capacity or model configuration temporarily unavailable.

Integration rules

  • Keep API keys server-side; do not expose them in browser or client bundles.
  • Send the minimum project context required to answer the workflow task.
  • Do not use systematic queries to reconstruct, mirror, train on, or redistribute the Framework corpus.
  • For model-training, OEM, high-volume, or redistribution rights, contact hello@postopz.com for an Enterprise / Model License.
